# Blog Manager - Full Stack CRUD Application

A full-stack blog management application built as part of the CodeVeda Web Development Internship.

## Features

- Create blog posts
- View all blog posts
- Edit existing posts
- Delete posts
- MongoDB database integration
- REST API using Express.js
- React frontend
- Responsive user interface
- Real-time UI updates after CRUD operations

## Technologies Used

### Frontend
- React
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Node.js
- Express.js
- REST API
- Mongoose

### Database
- MongoDB Atlas
